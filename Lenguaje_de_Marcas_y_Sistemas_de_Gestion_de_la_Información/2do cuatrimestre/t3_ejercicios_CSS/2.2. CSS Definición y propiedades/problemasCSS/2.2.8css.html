18 - Propiedades relacionadas a listas.

Confeccionar dos listas de lenguajes de programación. Agrupar los lenguajes estructurados (Pascal, C) y los lenguajes orientados a objetos (C++, Java, C#) Aplicar estilos distintos a cada lista.

  • Pascal
  • C

Crear dos listas e inicializar la propiedad list-style-position con los valores inside y outside respectivamente y analizar en que difieren.

  • Posición Inside: El marcador se mete dentro del bloque de texto.
  • Posición Outside: El marcador queda fuera.

Crear dos listas y asignar dos imágenes diferentes, una para cada lista, utiliza la propiedad list-style-image.
