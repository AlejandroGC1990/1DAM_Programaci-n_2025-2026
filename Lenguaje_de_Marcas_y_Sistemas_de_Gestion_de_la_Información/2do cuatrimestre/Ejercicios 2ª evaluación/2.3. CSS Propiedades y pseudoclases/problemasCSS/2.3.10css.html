30 - Propiedades relacionadas a la dimensión

Ejercicio de párrafos con dimensiones controladas

Crear una página HTML que muestre dos párrafos, a uno de ellos aplicarle
el siguiente estilo:
    .parrafoestrecho {
        width:200px;
        text-align:justify;
    }

Este es un párrafo normal. Como no tiene definida la propiedad width, su valor por defecto es "auto" y ocupa todo el ancho disponible.

Este párrafo tiene aplicado el estilo .parrafoestrecho. Su ancho está limitado a 200 píxeles y su texto aparece justificado, adaptándose exactamente a la dimensión que le hemos asignado.
