22 - Propiedades relacionadas al padding (Resumido)

Ejercicio de diferentes formatos de padding

Definir tres clases distintas con formatos diferentes para expresar el padding. Aplicar las clases a tres párrafos.

Párrafo 1: Utiliza un único valor para los cuatro lados.

Párrafo 2: Utiliza dos valores (superior/inferior y laterales).

Párrafo 3: Utiliza cuatro valores (uno para cada lado).
