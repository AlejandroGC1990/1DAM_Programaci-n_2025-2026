Inicio Ej. 5: Facturas XML/CSS

Enunciado - Ejercicios 1 y 2 (XML)

1. Diseñar un documento facturas.xml y su DTD para una cadena de alimentación.

2. Crear una hoja de estilo CSS para visualizar las facturas con el formato de colores específico (Fondo rojo, bloques verdes/naranja).

Resultado (Simulación Visual):

FACTURA: 1 CLIENTE: 0011
ARTICULO: Codigo: 0001 Nombre: PAN Cantidad: 2 Precio: 3
FACTURA: 2 CLIENTE: 0055
ARTICULO: Codigo: 0002 Nombre: AGUA Cantidad: 4 Precio: 5

Código Técnico:

Facturas.dtd

<!ELEMENT facturas (factura*)>
<!ELEMENT factura (cod_cliente, articulo+)>
<!ATTLIST factura facturaID CDATA #REQUIRED>
<!ATTLIST factura num-fac CDATA #IMPLIED>
<!ELEMENT cod_cliente (#PCDATA)>
<!ELEMENT articulo (nom_articulo, cantidad, precio)>
<!ATTLIST articulo cod_articulo CDATA #IMPLIED>
<!ELEMENT nom_articulo (#PCDATA)>
<!ELEMENT cantidad (#PCDATA)>F
<!ELEMENT precio (#PCDATA)>
