Inicio Ej. 3: Validación de DTDs

Enunciado - Ejercicio 3

Identificar y corregir errores estructurales en documentos XML con DTD interna.

Archivos Corregidos

Pulsa en cada enlace para ver el XML corregido y validado:

  • 📄 Escritores.xml (Orden de elementos corregido [cite: 91])
  • 📄 Musicos.xml (Etiquetas de cierre corregidas [cite: 120])
  • 📄 Agenda.xml (Uso correcto de cardinalidad [cite: 132])

Resumen Técnico de Correcciones

  1. Sincronización: Se ajustaron nombres de etiquetas que no coincidían con la raíz[cite: 57, 59].
  2. Secuenciación: Se respetó el orden estricto definido en la DTD (ej. Nombre antes que Nacimiento)[cite: 91, 92].
  3. Formato: Se eliminaron espacios prohibidos en nombres de etiquetas y se cerraron etiquetas huérfanas[cite: 120].
